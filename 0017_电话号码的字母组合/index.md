# 力扣17. Letter Combinations of a Phone Number（电话号码的字母组合）


## 力扣17. Letter Combinations of a Phone Number（电话号码的字母组合）

给定一个仅包含数字 2-9 的字符串，返回所有它能表示的字母组合。答案可以按任意顺序返回。数字到字母的映射与电话按键相同：2→abc, 3→def, 4→ghi, 5→jkl, 6→mno, 7→pqrs, 8→tuv, 9→wxyz。

示例 1：

![](../posts/01_学习/87_LeetCode/0017_电话号码的字母组合/img/0017-1-description.png)

```
输入：digits = "23"
输出：["ad","ae","af","bd","be","bf","cd","ce","cf"]
```

示例 2：

![](../posts/01_学习/87_LeetCode/0017_电话号码的字母组合/img/0017-2-description.png)

```
输入：digits = ""
输出：[]
```

示例 3：

![](../posts/01_学习/87_LeetCode/0017_电话号码的字母组合/img/0017-3-description.png)

```
输入：digits = "2"
输出：["a","b","c"]
```

提示：
- 0 <= digits.length <= 4
- digits[i] 是范围 ['2', '9'] 的一个数字
