## 力扣691. Stickers to Spell Word（贴纸拼词）

最少需要的贴纸数量。

示例 1：

![](../posts/01_学习/87_LeetCode/0691_贴纸拼词/img/0691-1-description.png)

```
输入：stickers = ["with","example","science"], target = "thehat"
输出：3
```

提示：
- n == stickers.length
- 1 <= n <= 50
- 1 <= stickers[i].length <= 10
- 1 <= target.length <= 15
