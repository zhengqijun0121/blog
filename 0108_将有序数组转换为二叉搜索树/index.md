## 力扣108. Convert Sorted Array to Binary Search Tree（将有序数组转换为二叉搜索树）

给你一个整数数组 nums，其中元素已经按升序排列，请你将其转换为一棵平衡二叉搜索树。

示例 1：

![](../posts/01_学习/87_LeetCode/0108_将有序数组转换为二叉搜索树/img/0108-1-description.png)

```
输入：nums = [-10,-3,0,5,9]
输出：[0,-3,9,-10,null,5]
解释：...
```

示例 2：

![](../posts/01_学习/87_LeetCode/0108_将有序数组转换为二叉搜索树/img/0108-2-description.png)

```
输入：nums = [1,3]
输出：[3,1]
解释：...
```

提示：
- 1 <= nums.length <= 10^4
- -10^4 <= nums[i] <= 10^4
