# 力扣654. Maximum Binary Tree（最大二叉树）


## 力扣654. Maximum Binary Tree（最大二叉树）

根据数组构建最大二叉树。

示例 1：

![](../posts/01_学习/87_LeetCode/0654_最大二叉树/img/0654-1-description.png)

```
输入：nums = [3,2,1,6,0,5]
输出：[6,3,5,null,2,0,null,null,1]
```

提示：
- 1 <= nums.length <= 1000
- 0 <= nums[i] <= 1000
- nums 中所有整数互不相同
