# 力扣51. N-Queens（N 皇后）


## 力扣51. N-Queens（N 皇后）

按照国际象棋的规则，皇后可以攻击与之处在同一行或同一列或同一斜线上的棋子。n 皇后问题研究的是如何将 n 个皇后放置在 n×n 的棋盘上，并且使皇后彼此之间不能相互攻击。给你一个整数 n，返回所有不同的 n 皇后问题的解决方案。每一种解法包含一个不同的皇后放置方案，其中 'Q' 和 '.' 分别代表了皇后和空位。

示例 1：

![](../posts/01_学习/87_LeetCode/0051_N皇后/img/0051-1-description.png)

```
输入：n = 4
输出：[[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]
解释：如下图所示，4 皇后问题存在两个不同的解法。
```

示例 2：

```
输入：n = 1
输出：[["Q"]]
```

提示：
- 1 <= n <= 9
