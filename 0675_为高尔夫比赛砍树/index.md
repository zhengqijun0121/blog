## 力扣675. Cut Off Trees for Golf Event（为高尔夫比赛砍树）

砍完所有树的最短路径。

示例 1：

![](../posts/01_学习/87_LeetCode/0675_为高尔夫比赛砍树/img/0675-1-description.png)

```
输入：[[1,2,3],[0,0,4],[7,6,5]]
输出：6
```

提示：
- 1 <= grid.length <= 50
- 1 <= grid[0].length <= 50
- 0 <= grid[i][j] <= 10^9
