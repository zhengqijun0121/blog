# 力扣182. Duplicate Emails（查找重复的电子邮箱）


## 力扣182. Duplicate Emails（查找重复的电子邮箱）

编写 SQL 查询，查找 Person 表中所有重复的电子邮箱。表：Person（id, email）。

示例 1：

![](../posts/01_学习/87_LeetCode/0182_查找重复的电子邮箱/img/0182-1-description.png)

```
输入：
Person table:
| id | email      |
|----|------------|
| 1  | a@b.com    |
| 2  | c@d.com    |
| 3  | a@b.com    |
输出：
| Email     |
|-----------|
| a@b.com   |
```

提示：
- 所有电子邮箱都是小写字母
