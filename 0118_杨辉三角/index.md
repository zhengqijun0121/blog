# 力扣118. 杨辉三角


## 力扣118. Pascal's Triangle（杨辉三角）

给定一个非负整数 numRows，生成杨辉三角的前 numRows 行。在杨辉三角中，每个数是它左上方和右上方的数的和。

示例 1：

![](../posts/01_学习/87_LeetCode/0118_杨辉三角/img/0118-1-description.png)

```
输入：numRows = 5
输出：[[1],[1,1],[1,2,1],[1,3,3,1],[1,4,6,4,1]]
```

示例 2：

```
输入：numRows = 1
输出：[[1]]
```

提示：
- 1 <= numRows <= 30
