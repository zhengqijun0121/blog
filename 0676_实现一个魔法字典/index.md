## 力扣676. Implement Magic Dictionary（实现一个魔法字典）

设计支持搜索只差一个字母的单词的字典。

示例 1：

![](../posts/01_学习/87_LeetCode/0676_实现一个魔法字典/img/0676-1-description.png)

```
输入：["MagicDictionary", "buildDict", "search", "search", "search", "search"]
[[], [["hello","leetcode"]], ["hello"], ["hhllo"], ["hell"], ["leetcoded"]]
输出：[null, null, false, true, false, false]
```

提示：
- 1 <= dictionary.length <= 100
- 1 <= dictionary[i].length <= 100
- dictionary[i] 由小写英文字母组成
