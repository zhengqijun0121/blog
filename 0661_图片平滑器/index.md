# 力扣661. Image Smoother（图片平滑器）


## 力扣661. Image Smoother（图片平滑器）

计算灰度平滑后的矩阵。

示例 1：

![](../posts/01_学习/87_LeetCode/0661_图片平滑器/img/0661-1-description.png)

```
输入：[[1,1,1],[1,0,1],[1,1,1]]
输出：[[0,0,0],[0,0,0],[0,0,0]]
```

提示：
- m == img.length, n == img[i].length
- 1 <= m, n <= 200
- 0 <= img[i][j] <= 255
