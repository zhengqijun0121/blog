# 力扣203. Remove Linked List Elements（移除链表元素）


## 力扣203. Remove Linked List Elements（移除链表元素）

给你一个链表的头节点 head 和一个整数 val，删除链表中所有满足 Node.val == val 的节点并返回新的头节点。

示例 1：

![](../posts/01_学习/87_LeetCode/0203_移除链表元素/img/0203-1-description.png)

```
输入：head = [1,2,6,3,4,5,6], val = 6
输出：[1,2,3,4,5]
```

提示：
- 列表中的节点数目在 [0, 10^4] 范围内
- 1 <= Node.val <= 50
- 0 <= val <= 50
