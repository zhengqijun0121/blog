## 力扣703. Kth Largest Element in a Stream（数据流中的第 K 大元素）

返回数据流中第 k 大的元素。

示例 1：

![](../posts/01_学习/87_LeetCode/0703_数据流中的第K大元素/img/0703-1-description.png)

```
输入：k = 3, nums = [4,5,8,2], add(3) -> 4
输出：[null, 4, 5, 5, 8, 8]
解释：...
```

提示：
- 1 <= k <= 10^5
- 0 <= nums.length <= 10^4
- -10^4 <= nums[i], val <= 10^4
