示例 1：

```
输入：words1 = ["great","acting","skills"], words2 = ["fine","drama","talent"], pairs = [["great","good"],["fine","good"],["acting","drama"],["skills","talent"]]
输出：true
解释：...
```

提示：
- 1 <= words1.length, words2.length <= 1000
- 0 <= pairs.length <= 2000
