## 力扣124. Binary Tree Maximum Path Sum（二叉树中的最大路径和）

二叉树中的路径被定义为一条节点序列，序列中每对相邻节点之间都有边。同一个节点在一条路径序列中至多出现一次。路径至少包含一个节点，且不一定经过根节点。给你一个二叉树的根节点 root，返回其最大路径和。

示例 1：

![](../posts/01_学习/87_LeetCode/0124_二叉树中的最大路径和/img/0124-1-description.png)

```
输入：root = [1,2,3]
输出：6
解释：最优路径是 2 -> 1 -> 3，路径和为 2 + 1 + 3 = 6。
```

示例 2：

![](../posts/01_学习/87_LeetCode/0124_二叉树中的最大路径和/img/0124-2-description.png)

```
输入：root = [-10,9,20,null,null,15,7]
输出：42
解释：最优路径是 15 -> 20 -> 7，路径和为 15 + 20 + 7 = 42。
```

提示：
- 树中节点数目范围是 [1, 3 * 10^4]
- -1000 <= Node.val <= 1000
