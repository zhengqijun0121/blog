# 力扣154. 寻找旋转排序数组中的最小值 II


## 力扣154. Find Minimum in Rotated Sorted Array II（寻找旋转排序数组中的最小值 II）

已知一个长度为 n 的数组，预先按照升序排列，在某个未知下标处进行了旋转。数组可能包含重复元素。请找出数组中的最小元素。

示例 1：

![](../posts/01_学习/87_LeetCode/0154_寻找旋转排序数组中的最小值II/img/0154-1-description.png)

```
输入：nums = [1,3,5]
输出：1
```

示例 2：

![](../posts/01_学习/87_LeetCode/0154_寻找旋转排序数组中的最小值II/img/0154-2-description.png)

```
输入：nums = [2,2,2,0,1]
输出：0
```

提示：
- n == nums.length
- 1 <= n <= 5000
- -5000 <= nums[i] <= 5000
- nums 原来是一个升序排序的数组，并在某个未知下标处进行了旋转

进阶：这道题与 153 题类似，但本题中的数组可能包含重复元素。你能减少时间复杂度吗？
