# 力扣537. 复数乘法


## 力扣537. Complex Number Multiplication（复数乘法）

复数可以用字符串表示，遵循 "实部+虚部i" 的形式。给你两个字符串表示的复数 num1 和 num2，请你返回它们的乘积，结果同样以复数形式表示。

示例 1：

```
输入：num1 = "1+1i", num2 = "1+1i"
输出："0+2i"
```

示例 2：

```
输入：num1 = "1+-1i", num2 = "1+-1i"
输出："0+-2i"
```

提示：
- num1 和 num2 都是有效的复数表示
- 实部和虚部都在范围 [-100, 100] 内
