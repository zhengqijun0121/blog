## 力扣686. Repeated String Match（重复叠加字符串匹配）

计算重复叠加字符串使包含另一字符串。

示例 1：

![](../posts/01_学习/87_LeetCode/0686_重复叠加字符串匹配/img/0686-1-description.png)

```
输入：a = "abcd", b = "cdabcdab"
输出：3
```

提示：
- 1 <= a.length <= 10^4
- 1 <= b.length <= 10^4
- a 和 b 由小写英文字母组成
