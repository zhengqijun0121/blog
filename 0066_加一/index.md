# 力扣66. Plus One（加一）


## 力扣66. Plus One（加一）

给定一个由**整数**组成的**非空**数组所表示的非负整数，在该数的基础上加一。

最高位数字存放在数组的首位，数组中每个元素只存储**单个**数字。

你可以假设除了整数 0 之外，这个整数不会以零开头。

示例 1：

![](../posts/01_学习/87_LeetCode/0066_加一/img/0066-1-description.png)

```
输入：digits = [1,2,3]
输出：[1,2,4]
解释：输入数组表示数字 123。
```

示例 2：

![](../posts/01_学习/87_LeetCode/0066_加一/img/0066-2-description.png)

```
输入：digits = [4,3,2,1]
输出：[4,3,2,2]
解释：输入数组表示数字 4321。
```

示例 3：

![](../posts/01_学习/87_LeetCode/0066_加一/img/0066-3-description.png)

```
输入：digits = [9]
输出：[1,0]
解释：输入数组表示数字 9。
```

提示：
- 1 <= digits.length <= 100
- 0 <= digits[i] <= 9
