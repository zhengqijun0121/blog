# 力扣60. Permutation Sequence（排列序列）


## 力扣60. Permutation Sequence（排列序列）

给出集合 [1,2,3,...,n]，其所有元素共有 n! 种排列。按大小顺序列出所有排列情况，并一一标记。给定 n 和 k，返回第 k 个排列。

示例 1：

![](../posts/01_学习/87_LeetCode/0060_排列序列/img/0060-1-description.png)

```
输入：n = 3, k = 3
输出："213"
```

示例 2：

![](../posts/01_学习/87_LeetCode/0060_排列序列/img/0060-2-description.png)

```
输入：n = 4, k = 9
输出："2314"
```

提示：
- 1 <= n <= 9
- 1 <= k <= n!
