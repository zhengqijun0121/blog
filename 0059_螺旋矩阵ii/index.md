# 力扣59. Spiral Matrix II（螺旋矩阵 II）


## 力扣59. Spiral Matrix II（螺旋矩阵 II）

给你一个正整数 n，生成一个包含 1 到 n² 所有元素，且元素按顺时针顺序螺旋排列的 n×n 正方形矩阵 matrix。

示例 1：

![](../posts/01_学习/87_LeetCode/0059_螺旋矩阵II/img/0059-1-description.png)

```
输入：n = 3
输出：[[1,2,3],[8,9,4],[7,6,5]]
```

示例 2：

![](../posts/01_学习/87_LeetCode/0059_螺旋矩阵II/img/0059-2-description.png)

```
输入：n = 1
输出：[[1]]
```

提示：
- 1 <= n <= 20
