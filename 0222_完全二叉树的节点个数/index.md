# 力扣222. 完全二叉树的节点个数


## 力扣222. Count Complete Tree Nodes（完全二叉树的节点个数）

给你一棵完全二叉树的根节点 root，求出该树的节点个数。

示例 1：

![](../posts/01_学习/87_LeetCode/0222_完全二叉树的节点个数/img/0222-1-description.png)

```
输入：root = [1,2,3,4,5,6]
输出：6
```

提示：
- 树中节点的数目范围是 [0, 5 * 10^4]
- 0 <= Node.val <= 5 * 10^4
- 题目数据保证输入的树是完全二叉树
