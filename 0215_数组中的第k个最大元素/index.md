# 力扣215. 数组中的第 K 个最大元素


## 力扣215. Kth Largest Element in an Array（数组中的第 K 个最大元素）

给定整数数组 nums 和整数 k，请返回数组中第 k 个最大的元素。

示例 1：

![](../posts/01_学习/87_LeetCode/0215_数组中的第K个最大元素/img/0215-1-description.png)

```
输入：nums = [3,2,1,5,6,4], k = 2
输出：5
```

提示：
- 1 <= k <= nums.length <= 10^5
- -10^4 <= nums[i] <= 10^4
