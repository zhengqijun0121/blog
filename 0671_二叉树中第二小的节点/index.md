# 力扣671. 二叉树中第二小的节点


## 力扣671. Second Minimum Node In a Binary Tree（二叉树中第二小的节点）

找到二叉树中第二小的值。

示例 1：

![](../posts/01_学习/87_LeetCode/0671_二叉树中第二小的节点/img/0671-1-description.png)

```
输入：root = [2,2,5,null,null,5,7]
输出：5
```

提示：
- 树中节点数在 [1, 25] 范围内
- 1 <= Node.val <= 2^31 - 1
- root.val == min(所有节点值)
