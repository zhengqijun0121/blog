## 力扣483. Largest Palindrome Product（最大回文数乘积）

给定一个整数 n，返回所有 n 位整数乘积中最大的回文数。由于结果可能非常大，你需要返回结果模 1337 的值。

示例 1：

![](../posts/01_学习/87_LeetCode/0483_最大回文数乘积/img/0483-1-description.png)

```
输入：n = 2
输出：987
解释：99 × 91 = 9009，9009 % 1337 = 987
```

示例 2：

```
输入：n = 1
输出：9
```

提示：
- 1 <= n <= 8
