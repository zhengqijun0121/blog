# 力扣224. Basic Calculator（基本计算器）


## 力扣224. Basic Calculator（基本计算器）

给你一个字符串表达式 s，实现一个基本计算器来计算并返回它的值。表达式包含 +、-、(、) 和空格。

示例 1：

![](../posts/01_学习/87_LeetCode/0224_基本计算器/img/0224-1-description.png)

```
输入：s = "1 + 1"
输出：2
```

提示：
- 1 <= s.length <= 3 * 10^5
- s 由数字、'+'、'-'、'('、')' 和空格组成
- s 表示一个有效的表达式
