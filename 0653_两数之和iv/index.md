# 力扣653. 两数之和 IV - 输入 BST


## 力扣653. Two Sum IV - Input is a BST（两数之和 IV - 输入 BST）

判断 BST 中是否存在两数和等于目标。

示例 1：

![](../posts/01_学习/87_LeetCode/0653_两数之和IV/img/0653-1-description.png)

```
输入：root = [5,3,6,2,4,null,7], k = 9
输出：true
```

提示：
- 树中节点数在 [1, 10^4] 范围内
- -10^4 <= Node.val <= 10^4
- 根唯一
- -10^5 <= k <= 10^5
