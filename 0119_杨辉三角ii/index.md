# 力扣119. Pascal's Triangle II（杨辉三角 II）


## 力扣119. Pascal's Triangle II（杨辉三角 II）

给定一个非负索引 rowIndex，返回杨辉三角的第 rowIndex 行。注意 rowIndex 从 0 开始。

示例 1：

```
输入：rowIndex = 3
输出：[1,3,3,1]
```

示例 2：

```
输入：rowIndex = 0
输出：[1]
```

示例 3：

```
输入：rowIndex = 1
输出：[1,1]
```

提示：
- 0 <= rowIndex <= 33

进阶：你能优化你的算法使其使用 O(rowIndex) 额外空间吗？
