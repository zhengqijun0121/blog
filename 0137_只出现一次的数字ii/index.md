## 力扣137. Single Number II（只出现一次的数字 II）

给你一个整数数组 nums，除某个元素仅出现一次外，其余每个元素都恰出现三次。请你找出并返回那个只出现了一次的元素。你必须设计并实现线性时间复杂度的算法，且不使用额外空间。

示例 1：

![](../posts/01_学习/87_LeetCode/0137_只出现一次的数字II/img/0137-1-description.png)

```
输入：nums = [2,2,3,2]
输出：3
```

示例 2：

![](../posts/01_学习/87_LeetCode/0137_只出现一次的数字II/img/0137-2-description.png)

```
输入：nums = [0,1,0,1,0,1,99]
输出：99
```

提示：
- 1 <= nums.length <= 3 * 10^4
- -2^31 <= nums[i] <= 2^31 - 1
