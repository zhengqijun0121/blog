# 力扣36. 有效的数独


## 力扣36. Valid Sudoku（有效的数独）

请你判断一个 9x9 的数独是否有效。只需要根据以下规则验证已经填入的数字是否有效即可：数字 1-9 在每一行只能出现一次，数字 1-9 在每一列只能出现一次，数字 1-9 在每一个以粗实线分隔的 3x3 宫内只能出现一次。

示例 1：

![](../posts/01_学习/87_LeetCode/0036_有效的数独/img/0036-1-description.png)

```
输入：board =
[["5","3",".",".","7",".",".",".","."]
,["6",".",".","1","9","5",".",".","."]
,[".","9","8",".",".",".",".","6","."]
,["8",".",".",".","6",".",".",".","3"]
,["4",".",".","8",".","3",".",".","1"]
,["7",".",".",".","2",".",".",".","6"]
,[".","6",".",".",".",".","2","8","."]
,[".",".",".","4","1","9",".",".","5"]
,[".",".",".",".","8",".",".","7","9"]]
输出：true
```

示例 2：

```
输入：board =
[["8","3",".",".","7",".",".",".","."]
,["6",".",".","1","9","5",".",".","."]
,[".","9","8",".",".",".",".","6","."]
,["8",".",".",".","6",".",".",".","3"]
,["4",".",".","8",".","3",".",".","1"]
,["7",".",".",".","2",".",".",".","6"]
,[".","6",".",".",".",".","2","8","."]
,[".",".",".","4","1","9",".",".","5"]
,[".",".",".",".","8",".",".","7","9"]]
输出：false
解释：第一列有两个 8
```

提示：
- board.length == 9
- board[i].length == 9
- board[i][j] 是数字 '1'-'9' 或 '.'
