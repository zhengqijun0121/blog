# 力扣673. 最长递增子序列的个数


## 力扣673. Number of Longest Increasing Subsequence（最长递增子序列的个数）

统计最长递增子序列的个数。

示例 1：

![](../posts/01_学习/87_LeetCode/0673_最长递增子序列的个数/img/0673-1-description.png)

```
输入：[1,3,5,4,7]
输出：2
解释：最长递增子序列 [1,3,5,7] 和 [1,3,4,7]
```

提示：
- 1 <= nums.length <= 2000
- -10^6 <= nums[i] <= 10^6
