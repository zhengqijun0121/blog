# 力扣27. Remove Element（移除元素）


## 力扣27. Remove Element（移除元素）

给你一个数组 nums 和一个值 val，你需要原地移除所有数值等于 val 的元素，并返回移除后数组的新长度。不要使用额外的数组空间，你必须仅使用 O(1) 额外空间并原地修改输入数组。元素的顺序可以改变。你不需要考虑数组中超出新长度后面的元素。

示例 1：

![](../posts/01_学习/87_LeetCode/0027_移除元素/img/0027-1-description.png)

```
输入：nums = [3,2,2,3], val = 3
输出：2, nums = [2,2,_,_]
解释：函数应该返回新的长度 2，并且原数组 nums 的前两个元素被修改为 2, 2。不需要考虑数组中超出新长度后面的元素。
```

示例 2：

![](../posts/01_学习/87_LeetCode/0027_移除元素/img/0027-2-description.png)

```
输入：nums = [0,1,2,2,3,0,4,2], val = 2
输出：5, nums = [0,1,4,0,3,_,_,_]
解释：函数应该返回新的长度 5，并且原数组 nums 的前五个元素被修改为 0, 1, 4, 0, 3。不需要考虑数组中超出新长度后面的元素。
```

提示：
- 0 <= nums.length <= 100
- 0 <= nums[i] <= 50
- 0 <= val <= 100
