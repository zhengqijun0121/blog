# 力扣669. 修剪二叉搜索树


## 力扣669. Trim a Binary Search Tree（修剪二叉搜索树）

修剪 BST 使节点值在 [low, high] 内。

示例 1：

![](../posts/01_学习/87_LeetCode/0669_修剪二叉搜索树/img/0669-1-description.png)

```
输入：root = [1,0,2], low = 1, high = 2
输出：[1,null,2]
```

提示：
- 树中节点数在 [1, 10^4] 范围内
- 0 <= Node.val <= 10^4
- low <= high
