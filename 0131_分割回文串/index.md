# 力扣131. Palindrome Partitioning（分割回文串）


## 力扣131. Palindrome Partitioning（分割回文串）

给你一个字符串 s，请你将 s 分割成一些子串，使每个子串都是回文串。返回 s 所有可能的分割方案。

示例 1：

![](../posts/01_学习/87_LeetCode/0131_分割回文串/img/0131-1-description.png)

```
输入：s = "aab"
输出：[["a","a","b"],["aa","b"]]
解释：...
```

示例 2：

![](../posts/01_学习/87_LeetCode/0131_分割回文串/img/0131-2-description.png)

```
输入：s = "a"
输出：[["a"]]
```

提示：
- 1 <= s.length <= 16
- s 仅由小写英文字母组成
