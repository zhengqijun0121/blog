# 力扣199. 二叉树的右视图


## 力扣199. Binary Tree Right Side View（二叉树的右视图）

给定一个二叉树的根节点 root，想象自己站在它的右侧，按照从顶部到底部的顺序，返回从右侧所能看到的节点值。

示例 1：

![](../posts/01_学习/87_LeetCode/0199_二叉树的右视图/img/0199-1-description.png)

```
输入：root = [1,2,3,null,5,null,4]
输出：[1,3,4]
```

示例 2：

![](../posts/01_学习/87_LeetCode/0199_二叉树的右视图/img/0199-2-description.png)

```
输入：root = [1,null,3]
输出：[1,3]
```

示例 3：

![](../posts/01_学习/87_LeetCode/0199_二叉树的右视图/img/0199-3-description.png)

```
输入：root = []
输出：[]
```

提示：
- 树中节点数目在范围 [0, 100] 内
- -100 <= Node.val <= 100
