# 力扣152. 乘积最大子数组


## 力扣152. Maximum Product Subarray（乘积最大子数组）

给你一个整数数组 nums，请你找出数组中乘积最大的非空连续子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

示例 1：

![](../posts/01_学习/87_LeetCode/0152_乘积最大子数组/img/0152-1-description.png)

```
输入：nums = [2,3,-2,4]
输出：6
解释：子数组 [2,3] 有最大乘积 6。
```

示例 2：

![](../posts/01_学习/87_LeetCode/0152_乘积最大子数组/img/0152-2-description.png)

```
输入：nums = [-2,0,-1]
输出：0
解释：结果不能为 2，因为 [-2,-1] 不是子数组。
```

提示：
- 1 <= nums.length <= 2 * 10^4
- -10 <= nums[i] <= 10
- nums 的任何前缀或后缀的乘积都保证是一个 32 位整数
