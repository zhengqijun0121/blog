# 力扣502. IPO（IPO）


## 力扣502. IPO（IPO）

最多 k 个项目，最大化资本。

示例 1：

![](../posts/01_学习/87_LeetCode/0502_IPO/img/0502-1-description.png)

```
输入：k = 2, w = 0, profits = [1,2,3], capital = [0,1,1]
输出：4
解释：先做资本要求为 0 的项目（利润 1），资本变为 1；再做资本要求为 1 且利润 2 的项目，资本变为 4。
```

提示：
- 1 <= k <= 10^5
- 0 <= w <= 10^9
- n == profits.length == capital.length
- 1 <= n <= 10^5
