# 力扣104. 二叉树的最大深度


## 力扣104. Maximum Depth of Binary Tree（二叉树的最大深度）

给定一个二叉树 root，返回其最大深度。二叉树的最大深度是指从根节点到最远叶子节点的最长路径上的节点数。

示例 1：

![](../posts/01_学习/87_LeetCode/0104_二叉树的最大深度/img/0104-1-description.png)

```
输入：root = [3,9,20,null,null,15,7]
输出：3
解释：...
```

示例 2：

```
输入：root = [1,null,2]
输出：2
解释：...
```

提示：
- 树中节点数目在范围 [0, 10^4] 内
- -100 <= Node.val <= 100
