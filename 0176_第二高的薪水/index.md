# 力扣176. 第二高的薪水


## 力扣176. Second Highest Salary（第二高的薪水）

查询并返回 `Employee` 表中第二高的薪水。如果不存在第二高的薪水，查询应返回 `null`。

表结构：

**Employee**
| Column Name | Type |
|-------------|------|
| id          | int  |
| salary      | int  |

id 是主键。

示例 1：

![](../posts/01_学习/87_LeetCode/0176_第二高的薪水/img/0176-1-description.png)

```
输入：
Employee 表：
| id | salary |
|----|--------|
| 1  | 100    |
| 2  | 200    |
| 3  | 300    |

输出：
| SecondHighestSalary |
|---------------------|
| 200                 |
```
