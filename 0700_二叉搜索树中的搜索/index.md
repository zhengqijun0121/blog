# 力扣700. 二叉搜索树中的搜索


## 力扣700. Search in a Binary Search Tree（二叉搜索树中的搜索）

在 BST 中搜索指定值。

示例 1：

![](../posts/01_学习/87_LeetCode/0700_二叉搜索树中的搜索/img/0700-1-description.png)

```
输入：root = [4,2,7,1,3], val = 2
输出：[2,1,3]
```

提示：
- 树中节点数在 [1, 5000] 范围内
- 1 <= Node.val <= 10^7
- root 是二叉搜索树
- 1 <= val <= 10^7
