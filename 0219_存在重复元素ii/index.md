# 力扣219. 存在重复元素 II


## 力扣219. Contains Duplicate II（存在重复元素 II）

给你一个整数数组 nums 和一个整数 k，判断数组中是否存在两个不同索引的相同元素，且索引差不超过 k。

示例 1：

![](../posts/01_学习/87_LeetCode/0219_存在重复元素II/img/0219-1-description.png)

```
输入：nums = [1,2,3,1], k = 3
输出：true
```

提示：
- 1 <= nums.length <= 10^5
- -10^9 <= nums[i] <= 10^9
- 0 <= k <= 10^5
