# 力扣194. 转置文件


## 力扣194. Transpose File（转置文件）

给定一个文件 file.txt，请输出这个文件转置后的内容。file.txt 每一行的列数相同，每个字段由空格分隔。

示例 1：

![](../posts/01_学习/87_LeetCode/0194_转置文件/img/0194-1-description.png)

```
假设 file.txt 内容如下：
name age
alice 21
ryan 30

输出：
name alice ryan
age 21 30
```

提示：
- 输入文件的列数相同
- 每个字段由单个空格分隔
