# 力扣163. 缺失的区间


## 力扣163. Missing Ranges（缺失的区间）

给定一个排序的整数数组 nums，其中元素的范围在闭区间 [lower, upper] 内，请找出所有缺失的区间。缺失的区间是指那些在 [lower, upper] 范围内但不在数组中的连续整数区间。

此题是 LeetCode 会员题。

示例 1：

![](../posts/01_学习/87_LeetCode/0163_缺失的区间/img/0163-1-description.png)

```
输入：nums = [0,1,3,50,75], lower = 0, upper = 99
输出：["2","4->49","51->74","76->99"]
解释：缺失的区间为 [2,2], [4,49], [51,74], [76,99]
```

提示：

- 0 <= nums.length <= 100
- -2^31 <= lower <= nums[i] <= upper <= 2^31 - 1
