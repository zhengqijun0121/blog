# 力扣658. 找到 K 个最接近的元素


## 力扣658. Find K Closest Elements（找到 K 个最接近的元素）

找到数组中离 x 最近的 k 个数。

示例 1：

![](../posts/01_学习/87_LeetCode/0658_找到K个最接近的元素/img/0658-1-description.png)

```
输入：arr = [1,2,3,4,5], k = 4, x = 3
输出：[1,2,3,4]
```

提示：
- 1 <= k <= arr.length <= 10^4
- arr 按升序排列
- -10^4 <= arr[i], x <= 10^4
