## 力扣22. Generate Parentheses（括号生成）

数字 n 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且有效的括号组合。

示例 1：

![](../posts/01_学习/87_LeetCode/0022_括号生成/img/0022-1-description.png)

```
输入：n = 3
输出：["((()))","(()())","(())()","()(())","()()()"]
解释：...
```

示例 2：

```
输入：n = 1
输出：["()"]
```

提示：
- 1 <= n <= 8
