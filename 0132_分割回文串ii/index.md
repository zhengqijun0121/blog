# 力扣132. 分割回文串 II


## 力扣132. Palindrome Partitioning II（分割回文串 II）

给你一个字符串 s，请你将 s 分割成一些子串，使每个子串都是回文串。返回符合要求的最少分割次数。

示例 1：

![](../posts/01_学习/87_LeetCode/0132_分割回文串II/img/0132-1-description.png)

```
输入：s = "aab"
输出：1
解释：...
```

示例 2：

![](../posts/01_学习/87_LeetCode/0132_分割回文串II/img/0132-2-description.png)

```
输入：s = "a"
输出：0
```

提示：
- 1 <= s.length <= 2000
- s 仅由小写英文字母组成
