# 力扣845. 数组中的最长山脉


## 力扣845. 数组中的最长山脉

把符合下列属性的数组 `arr` 称为 **山脉数组** ：



- `arr.length >= 3`

- 存在下标 `i`（`0 arr[i + 1] > ... > arr[arr.length - 1]`


给出一个整数数组 `arr`，返回最长山脉子数组的长度。如果不存在山脉子数组，返回 `0` 。

**示例 1：**


```
输入：arr = [2,1,4,7,3,2,5]
输出：5
解释：最长的山脉子数组是 [1,4,7,3,2]，长度为 5。
```


**示例 2：**


```
输入：arr = [2,2,2]
输出：0
解释：不存在山脉子数组。
```


**提示：**



- `1 <= arr.length <= 10^{4}`

- `0 <= arr[i] <= 10^{4}`

**进阶：**



- 你可以仅用一趟扫描解决此问题吗？

- 你可以用 `O(1)` 空间解决此问题吗？
