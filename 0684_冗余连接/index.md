## 力扣684. Redundant Connection（冗余连接）

找到无向图中可删除的一条边。

示例 1：

![](../posts/01_学习/87_LeetCode/0684_冗余连接/img/0684-1-description.png)

```
输入：[[1,2],[1,3],[2,3]]
输出：[2,3]
```

提示：
- n == edges.length
- 3 <= n <= 1000
- edges[i].length == 2
- 1 <= ai < bi <= edges.length
