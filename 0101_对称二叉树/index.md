示例 1：

![](../posts/01_学习/87_LeetCode/0101_对称二叉树/img/0101-1-description.png)

```
输入：root = [1,2,2,3,4,4,3]
输出：true
解释：...
```

示例 2：

![](../posts/01_学习/87_LeetCode/0101_对称二叉树/img/0101-2-description.png)

```
输入：root = [1,2,2,null,3,null,3]
输出：false
解释：...
```

提示：
- 树中节点数目在范围 [1, 1000] 内
- -100 <= Node.val <= 100
