# 力扣238. 除自身以外数组的乘积


## 力扣238. Product of Array Except Self（除自身以外数组的乘积）

给你一个整数数组 nums，返回数组 answer 使得 answer[i] 等于 nums 中除 nums[i] 之外其余各元素的乘积。

示例 1：

![](../posts/01_学习/87_LeetCode/0238_除自身以外数组的乘积/img/0238-1-description.png)

```
输入：nums = [1,2,3,4]
输出：[24,12,8,6]
```

提示：
- 2 <= nums.length <= 10^5
- -30 <= nums[i] <= 30
- 题目数据保证数组之中任意元素的全部前缀元素和后缀的乘积都在 32 位整数范围内
