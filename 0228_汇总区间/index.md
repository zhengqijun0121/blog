# 力扣228. 汇总区间


## 力扣228. Summary Ranges（汇总区间）

给定一个无重复元素的有序整数数组 nums，返回恰好覆盖数组中所有数字的最小有序区间范围列表。

示例 1：

![](../posts/01_学习/87_LeetCode/0228_汇总区间/img/0228-1-description.png)

```
输入：nums = [0,1,2,4,5,7]
输出：["0->2","4->5","7"]
```

提示：
- 0 <= nums.length <= 20
- -2^31 <= nums[i] <= 2^31 - 1
- nums 中的所有值都互不相同
- nums 按升序排列
