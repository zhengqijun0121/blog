## 力扣24. Swap Nodes in Pairs（两两交换链表中的节点）

给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。你必须在不修改节点内部的值的情况下完成本题（即只能进行节点交换）。

示例 1：

![](../posts/01_学习/87_LeetCode/0024_两两交换链表中的节点/img/0024-1-description.png)

```
输入：head = [1,2,3,4]
输出：[2,1,4,3]
解释：...
```

示例 2：

```
输入：head = []
输出：[]
```

示例 3：

```
输入：head = [1]
输出：[1]
```

提示：
- 链表中节点的数目在范围 [0, 100] 内
- 0 <= Node.val <= 100
