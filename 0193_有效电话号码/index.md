## 力扣193. Valid Phone Numbers（有效电话号码）

给定一个包含电话号码列表的文本文件 file.txt，请输出所有有效的电话号码。有效的电话号码格式为：(xxx) xxx-xxxx 或 xxx-xxx-xxxx（x 表示数字）。

示例 1：

![](../posts/01_学习/87_LeetCode/0193_有效电话号码/img/0193-1-description.png)

```
假设 file.txt 内容如下：
987-123-4567
123 456 7890
(123) 456-7890

输出：
987-123-4567
(123) 456-7890
```

提示：
- 电话号码可能包含空格、括号和连字符
- 只输出匹配上述两种格式的电话号码
