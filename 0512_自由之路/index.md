# 力扣514. 自由之路


## 力扣514. Freedom Trail（自由之路）

电子游戏"辐射4"中，有一个解密小游戏"自由之路"。给定一个圆盘，上面刻有一个字符串 ring。你需要通过旋转圆盘拼出另一个字符串 key。计算拼出 key 所需要的最少步数。

示例 1：

![](../posts/01_学习/87_LeetCode/0512_自由之路/img/0512-1-description.png)

```
输入：ring = "godding", key = "gd"
输出：4
```

示例 2：

```
输入：ring = "godding", key = "godding"
输出：13
```

提示：
- 1 <= ring.length, key.length <= 100
- ring 和 key 仅由小写英文字母组成
