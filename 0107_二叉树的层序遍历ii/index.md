# 力扣107. 二叉树的层序遍历 II


## 力扣107. Binary Tree Level Order Traversal II（二叉树的层序遍历 II）

给你二叉树的根节点 root，返回其节点值自底向上的层序遍历。（即按从叶子节点所在层到根节点所在的层，逐层从左向右遍历）。

示例 1：

![](../posts/01_学习/87_LeetCode/0107_二叉树的层序遍历II/img/0107-1-description.png)

```
输入：root = [3,9,20,null,null,15,7]
输出：[[15,7],[9,20],[3]]
解释：...
```

示例 2：

```
输入：root = [1]
输出：[[1]]
解释：...
```

示例 3：

```
输入：root = []
输出：[]
解释：...
```

提示：
- 树中节点数目在范围 [0, 2000] 内
- -1000 <= Node.val <= 1000
