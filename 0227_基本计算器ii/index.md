# 力扣227. Basic Calculator II（基本计算器 II）


## 力扣227. Basic Calculator II（基本计算器 II）

给你一个字符串表达式 s，实现一个基本计算器来计算并返回它的值。表达式包含 +、-、*、/ 和空格。

示例 1：

![](../posts/01_学习/87_LeetCode/0227_基本计算器II/img/0227-1-description.png)

```
输入：s = "3+2*2"
输出：7
```

提示：
- 1 <= s.length <= 3 * 10^5
- s 由整数和运算符（'+'、'-'、'*'、'/'）组成，中间由一些空格隔开
- s 表示一个有效的表达式
- 表达式中的所有整数都是非负整数，且在范围 [0, 2^31 - 1] 内
- 题目数据保证答案是一个 32 位整数
