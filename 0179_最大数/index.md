# 力扣179. Largest Number（最大数）


## 力扣179. Largest Number（最大数）

给定一组非负整数 `nums`，重新排列每个数的顺序（每个数不可拆分）使之组成一个最大的整数。结果可能非常大，以字符串返回。

示例 1：

![](../posts/01_学习/87_LeetCode/0179_最大数/img/0179-1-description.png)

```
输入：nums = [10,2]
输出："210"
```

示例 2：

![](../posts/01_学习/87_LeetCode/0179_最大数/img/0179-2-description.png)

```
输入：nums = [3,30,34,5,9]
输出："9534330"
```

提示：
- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 10^9`
