# 力扣161. 相隔为 1 的编辑距离


## 力扣161. One Edit Distance（相隔为 1 的编辑距离）

给定两个字符串 s 和 t，如果它们之间只有一个编辑距离，则返回 true，否则返回 false。

编辑距离包括：插入一个字符、删除一个字符、替换一个字符。

此题是 LeetCode 会员题。

示例 1：

![](../posts/01_学习/87_LeetCode/0161_相隔为1的编辑距离/img/0161-1-description.png)

```
输入：s = "ab", t = "acb"
输出：true
解释：t 中插入 'c' 变为 s
```

提示：

- 0 <= s.length, t.length <= 10^4
- s 和 t 由小写英文字母组成
