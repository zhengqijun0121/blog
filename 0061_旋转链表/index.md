# 力扣61. Rotate List（旋转链表）


## 力扣61. Rotate List（旋转链表）

给你一个链表的头节点 head，旋转链表，将链表每个节点向右移动 k 个位置。

示例 1：

![](../posts/01_学习/87_LeetCode/0061_旋转链表/img/0061-1-description.png)

```
输入：head = [1,2,3,4,5], k = 2
输出：[4,5,1,2,3]
```

示例 2：

![](../posts/01_学习/87_LeetCode/0061_旋转链表/img/0061-2-description.png)

```
输入：head = [0,1,2], k = 4
输出：[2,0,1]
```

提示：
- 链表中节点数目在范围 [0, 500] 内
- -100 <= Node.val <= 100
- 0 <= k <= 2 * 10^9
