## 力扣688. Knight Probability in Chessboard（骑士在棋盘上的概率）

计算骑士留在棋盘上的概率。

示例 1：

![](../posts/01_学习/87_LeetCode/0688_骑士在棋盘上的概率/img/0688-1-description.png)

```
输入：n = 3, k = 2, row = 0, column = 0
输出：0.0625
```

提示：
- 1 <= n <= 25
- 0 <= k <= 100
- 0 <= row, column <= n
