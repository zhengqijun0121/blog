# 力扣77. 组合


## 力扣77. Combinations（组合）

给定两个整数 n 和 k，返回范围 [1, n] 中所有可能的 k 个数的组合。你可以按任何顺序返回答案。

示例 1：

![](../posts/01_学习/87_LeetCode/0077_组合/img/0077-1-description.png)

```
输入：n = 4, k = 2
输出：[[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]
```

示例 2：

```
输入：n = 1, k = 1
输出：[[1]]
```

提示：
- 1 <= n <= 20
- 1 <= k <= n
