# 力扣94. 二叉树的中序遍历


## 力扣94. Binary Tree Inorder Traversal（二叉树的中序遍历）

给定一个二叉树的根节点 root，返回它的中序遍历。

示例 1：

![](../posts/01_学习/87_LeetCode/0094_二叉树的中序遍历/img/0094-1-description.png)

```
输入：root = [1,null,2,3]
输出：[1,3,2]
```

示例 2：

```
输入：root = []
输出：[]
```

示例 3：

```
输入：root = [1]
输出：[1]
```

提示：
- 树中节点数目在范围 [0, 100] 内
- -100 <= Node.val <= 100

进阶：递归算法很简单，你可以通过迭代算法完成吗？
