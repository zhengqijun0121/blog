# 力扣144. 二叉树的前序遍历


## 力扣144. Binary Tree Preorder Traversal（二叉树的前序遍历）

给你二叉树的根节点 root，返回它节点值的前序遍历。

示例 1：

![](../posts/01_学习/87_LeetCode/0144_二叉树的前序遍历/img/0144-1-description.png)

```
输入：root = [1,null,2,3]
输出：[1,2,3]
```

提示：
- 树中节点数目在范围 [0, 100] 内
- -100 <= Node.val <= 100

进阶：递归算法很简单，你可以通过迭代算法完成吗？
