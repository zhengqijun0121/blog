## 力扣83. Remove Duplicates from Sorted List（删除排序链表中的重复元素）

给定一个已排序的链表的头 head，删除所有重复的元素，使每个元素只出现一次。返回已排序的链表。

示例 1：

![](../posts/01_学习/87_LeetCode/0083_删除排序链表中的重复元素/img/0083-1-description.png)

```
输入：head = [1,1,2]
输出：[1,2]
```

示例 2：

![](../posts/01_学习/87_LeetCode/0083_删除排序链表中的重复元素/img/0083-2-description.png)

```
输入：head = [1,1,2,3,3]
输出：[1,2,3]
```

提示：
- 链表中节点数目在范围 [0, 300] 内
- -100 <= Node.val <= 100
