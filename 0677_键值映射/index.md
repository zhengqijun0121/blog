# 力扣677. 键值映射


## 力扣677. Map Sum Pairs（键值映射）

实现键值映射，支持前缀求和。

示例 1：

![](../posts/01_学习/87_LeetCode/0677_键值映射/img/0677-1-description.png)

```
输入：["MapSum", "insert", "sum", "insert", "sum"]
[[], ["apple",3], ["ap"], ["app",2], ["ap"]]
输出：[null, null, 3, null, 5]
```

提示：
- 1 <= key.length <= 50
- key 由小写英文字母组成
- 1 <= val <= 1000
