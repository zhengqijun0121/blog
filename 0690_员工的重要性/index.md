## 力扣690. Employee Importance（员工的重要性）

计算员工及其下属的重要性总和。

示例 1：

![](../posts/01_学习/87_LeetCode/0690_员工的重要性/img/0690-1-description.png)

```
输入：employees = [[1,5,[2,3]],[2,3,[]],[3,3,[]]], id = 1
输出：11
```

提示：
- 1 <= employees.length <= 2000
- 1 <= employees[i].id <= 2000
- -100 <= importance <= 100
