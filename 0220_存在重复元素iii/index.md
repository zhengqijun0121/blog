## 力扣220. Contains Duplicate III（存在重复元素 III）

给你一个整数数组 nums 和两个整数 k 和 t，判断是否存在两个不同位置的元素，使得差 ≤ t 且索引差 ≤ k。

示例 1：

![](../posts/01_学习/87_LeetCode/0220_存在重复元素III/img/0220-1-description.png)

```
输入：nums = [1,2,3,1], k = 3, t = 0
输出：true
```

提示：
- 0 <= nums.length <= 2 * 10^4
- -2^31 <= nums[i] <= 2^31 - 1
- 0 <= k <= 10^4
- 0 <= t <= 2^31 - 1
