# 力扣67. Add Binary（二进制求和）


## 力扣67. Add Binary（二进制求和）

给你两个二进制字符串 `a` 和 `b`，以二进制字符串的形式返回它们的和。

示例 1：

![](../posts/01_学习/87_LeetCode/0067_二进制求和/img/0067-1-description.png)

```
输入：a = "11", b = "1"
输出："100"
```

示例 2：

![](../posts/01_学习/87_LeetCode/0067_二进制求和/img/0067-2-description.png)

```
输入：a = "1010", b = "1011"
输出："10101"
```

提示：
- 1 <= a.length, b.length <= 10^4
- `a` 和 `b` 仅由字符 `'0'` 或 `'1'` 组成
- 字符串如果不是 `"0"`，就不含前导零
