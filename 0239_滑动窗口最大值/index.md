# 力扣239. 滑动窗口最大值


## 力扣239. Sliding Window Maximum（滑动窗口最大值）

给你一个整数数组 nums 和一个大小为 k 的滑动窗口，返回每个窗口中的最大值。

示例 1：

![](../posts/01_学习/87_LeetCode/0239_滑动窗口最大值/img/0239-1-description.png)

```
输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[3,3,5,5,6,7]
```

提示：
- 1 <= nums.length <= 10^5
- -10^4 <= nums[i] <= 10^4
- 1 <= k <= nums.length
