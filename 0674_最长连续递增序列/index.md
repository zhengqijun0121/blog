# 力扣674. Longest Continuous Increasing Subsequence（最长连续递增序列）


## 力扣674. Longest Continuous Increasing Subsequence（最长连续递增序列）

找到最长连续递增子序列的长度。

示例 1：

![](../posts/01_学习/87_LeetCode/0674_最长连续递增序列/img/0674-1-description.png)

```
输入：[1,3,5,4,7]
输出：3
解释：[1,3,5]
```

提示：
- 1 <= nums.length <= 10^4
- -10^9 <= nums[i] <= 10^9
