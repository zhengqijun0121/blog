# 力扣164. 最大间距


## 力扣164. Maximum Gap（最大间距）

给定一个无序的数组 nums，找出数组在排序之后相邻元素之间最大的差值。如果数组元素个数小于 2，则返回 0。

你必须设计并实现线性时间复杂度的算法。

示例 1：

![](../posts/01_学习/87_LeetCode/0164_最大间距/img/0164-1-description.png)

```
输入：nums = [3,6,9,1]
输出：3
解释：排序后的数组是 [1,3,6,9]，其中相邻元素 (3,6) 和 (6,9) 之间都存在最大差值 3。
```

示例 2：

![](../posts/01_学习/87_LeetCode/0164_最大间距/img/0164-2-description.png)

```
输入：nums = [10]
输出：0
解释：数组元素个数小于 2，返回 0。
```

提示：

- 1 <= nums.length <= 10^5
- 0 <= nums[i] <= 10^9
